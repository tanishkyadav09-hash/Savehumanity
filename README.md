# SaveHumanity by AlexKo

**Plant Today, Protect Tomorrow**

A production-ready, enterprise-level environmental NGO website built with modern web technologies.

## 🌿 Project Overview

SaveHumanity is a comprehensive platform for environmental conservation and tree plantation initiatives. It features a premium dark-themed UI with neon green accents, real-time impact tracking, volunteer management, donation system, and an admin dashboard for complete project management.

## 🏗️ Tech Stack

### Frontend
- **Next.js 15** - React framework with SSR/SSG
- **React 19** - UI library
- **TypeScript** - Type safety
- **Tailwind CSS** - Utility-first CSS
- **ShadCN UI** - Premium UI components
- **Framer Motion** - Advanced animations
- **GSAP** - Animation library

### Backend
- **Node.js** - Runtime
- **Express.js** - Web framework
- **MongoDB Atlas** - NoSQL database
- **Mongoose** - ODM
- **JWT** - Authentication
- **Razorpay** - Payment gateway
- **Cloudinary** - Image/Video storage

### Deployment
- **Vercel** - Frontend hosting
- **Railway/Render** - Backend hosting
